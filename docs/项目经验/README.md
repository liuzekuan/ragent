# 项目经验

这个目录用于沉淀在 `ragent` 项目中学到的知识、踩坑记录、架构理解、问题排查过程与最佳实践。

## 已有文章

## 建议记录的内容

### 1. 架构理解
- 模块职责划分
- 核心调用链路
- 关键中间件的作用
- 数据流与控制流

### 2. 开发踩坑
- 容易误解的设计
- 配置项陷阱
- 第三方组件行为差异
- 本地开发与生产环境差异

### 3. 问题排查
- 异常现象
- 根因分析
- 排查步骤
- 最终修复方案

### 4. 安全与运维
- 文件存储与访问控制
- 第三方平台数据流转
- 日志脱敏注意事项
- 公共资源暴露风险

## 推荐文件命名方式

建议按主题拆分，避免所有内容都堆到一个文件里，例如：

- `认证与权限.md`
- `文档解析链路.md`
- `对象存储与访问控制.md`
- `知识库分块机制.md`
- `问题排查记录-xxxx.md`

## 记录模板
